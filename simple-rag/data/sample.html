Vector Databases Explained

A vector database stores high-dimensional embedding vectors and answers nearest-neighbor queries efficiently. ChromaDB is a popular open-source vector database that runs embedded in a Python process or as a standalone server, making it a good fit for local development and prototyping.

Similarity search

When a query arrives, the database embeds it and compares the query vector against stored vectors using a distance metric such as cosine distance or squared L2. The chunks with the smallest distance are the most semantically similar, even when they share no exact keywords with the query.

Metadata filtering

Production systems usually attach metadata to each chunk, such as the source filename, page number, or tenant identifier. Filtering on metadata before or alongside the similarity search lets one collection serve many documents and many users safely.
